
Typer

= Typer is a modern Python library used to create command-line applications (CLI).

Example Commands:

python main.py add "Learn Python"
python main.py list
python main.py delete 1

Benefits:

= Uses Python type hints

= Generates help messages automatically

= Cleaner and easier to use than argparse

= Makes it easy to create multiple commands

Common Uses:

= Task managers

= Developer tools

= Deployment scripts

= Automation tools

= Administrative utilities

Note:

= Like argparse, users provide information when starting the program.

= Typer is a modern alternative to argparse for building CLI applications.



argparse

= argparse is a built-in Python module used to create command-line applications (CLI).

Example Commands:

python app.py Redd
python app.py --help

Benefits:

= Built into Python

= Parses command-line arguments

= Generates help messages automatically

= Commonly used for automation and scripting

Common Uses:

= Backup scripts

= File processing tools

= Deployment scripts

= Automation tools

Note:

= Unlike input(), users provide information when starting the program.
